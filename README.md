# Практическое задание №1. Классификация полнографических гистологических изображений

Решение задачи классификации фрагментов полнографических гистологических изображений (224×224, RGB) на 9 классов тканей и фона: `ADI`, `BACK`, `DEB`, `LYM`, `MUC`, `MUS`, `NORM`, `STR`, `TUM`.

## Структура репозитория
- `README.md` — описание подхода, реализованных дополнений и итоговых метрик.
- `histology-task1-sc.ipynb` — основной ноутбук с кодом, загрузкой обученных весов и результатами тестирования.
- `histology-task1-sc.pdf` — PDF-версия выполненного ноутбука со всеми выводами ячеек.

Веса обученной модели (`best.npz`) загружаются автоматически из облачного хранилища в методе `Model.load('best')`. 

## Описание решения

Было принято решение использовать комбо подход, объединяющий признаки предобученной CNN и ручные признаки изображения:

1. **Извлечение признаков (786 признаков на изображение):**
   - **Глубокие признаки (768):** эмбеддинги из предобученной `ConvNeXt-Tiny` с убранным последним классификационным слоем.
   - **Классические признаки (18, функция `vichislprizn` с ускорением через `numba`):**
     - средние и стандартные отклонения по каналам R, G, B и в оттенках серого;
     - доли светлых и тёмных пикселей (помогают отделять фон и плотные структуры вроде);
     - характеристики градиента (среднее и стандартное отклонение) и лапласиана;
     - текстурные признаки по матрице смежности уровней серого (GLCM 16×16): энергия, контраст, однородность и корреляция.
   - Перед обучением признаки стандартизируются через `StandardScaler`.

2. **Аугментации:**
   - Гистологические патчи не имеют фиксированной «верхней» или «нижней» ориентации, а оттенок и яркость могут немного меняться в зависимости от окрашивания и сканера.
   - На обучении (функция `tti`) применяются повороты на 90°/180°/270°, горизонтальные отражения и небольшие случайные сдвиги яркости и контраста по каналам.
   - На этапе предсказания (TTA в `_predictp`) усредняются вероятности по всем 8 симметриям квадрата (повороты и отражения).

3. **Ансамбль классификаторов:**
   - **Логистическая регрессия** (`LogisticRegression` с `class_weight='balanced'` для устойчивости к возможному дисбалансу классов). Параметр регуляризации `C` подбирается автоматически на 3-фолдовой кросс-валидации по `balanced_accuracy_score`.
   - **Умные веса (`SmartWeightHead`)** — полносвязная сеть с простым механизмом взвешивания признаков (attention-гейт через `Linear + Sigmoid`), `BatchNorm`, `ReLU` и `Dropout`. Обучается с `FocalLoss` (с `label_smoothing=0.04`) и оптимизатором `AdamW`
   - Вероятности двух моделей смешиваются с весом `vml`, который автоматически подбирается на валидационной выборке по максимуму сбалансированной точности.
